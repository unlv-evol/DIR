# Researcher analyses

The former `pilot_analysis/cases/` and `synthesis/` directories contained only empty placeholders and were removed. Earlier exploratory methodology remains in Git history and decision records; it is neither a Protocol v5 discovery assignment nor reconstruction-safe input.

In Protocol v5, conversation-side first-generation and supplied-C/S/V records are prepared from isolated conversation packages, independently validated on an approximately 30% PA/PN-stratified sample, and versioned before project-side discovery. Retrieval-pattern analyses then use only discovery cases after the split. Held-out project evidence cannot shape Retrieval Algorithm v1. See [the protocol](../protocols/experiment_protocol.md).

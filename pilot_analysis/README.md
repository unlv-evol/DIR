# Researcher analyses

Existing `pilot_analysis/cases/` and `synthesis/` are legacy exploratory work from the former approximately-30-case development design. Preserve them for provenance; they are neither Protocol v5 discovery assignments nor reconstruction-safe inputs.

In Protocol v5, conversation-side first-generation and supplied-C/S/V records are prepared from isolated conversation packages, independently validated on an approximately 30% PA/PN-stratified sample, and versioned before project-side discovery. Retrieval-pattern analyses then use only discovery cases after the split. Held-out project evidence cannot shape Retrieval Algorithm v1. See [the protocol](../protocols/pilot_case_selection_and_extraction.md).

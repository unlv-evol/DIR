You can avoid redundancy in your code by dynamically rendering the FAB components using an array of markers and mapping through them. Here's how you can do it:

```jsx
const markers = [
    { name: 'cone', icon: cone },
    { name: 'pothole', icon: pothole },
    { name: 'roadDamage', icon: roadDamage },
    { name: 'carAccident', icon: carAccident },
    { name: 'warningSign', icon: warning },
    { name: 'etc', icon: MoreHoriz },
];

return (
    <>
        {markers.map((marker, index) => (
            <Fab
                key={index}
                className={`${styles['CreatePost__fab']} ${selectedMarker === marker.name ? styles['CreatePost__active'] : ''}`}
                size="large"
                aria-label={marker.name}
                onClick={() => markerClick(marker.name)}
            >
                {typeof marker.icon === 'string' ? (
                    <img
                        className={styles['CreatePost__images']}
                        src={marker.icon}
                        alt=""
                    />
                ) : (
                    <marker.icon className={styles['CreatePost__images']} />
                )}
            </Fab>
        ))}
    </>
);
```

This code dynamically renders the FAB components based on the `markers` array. It maps through each marker and renders a FAB component for each one. The `selectedMarker` state variable is used to determine whether a marker is active, and the `markerClick` function is called when a FAB component is clicked.

Certainly! The following regular expression can be used to match the ULID (Universally Unique Lexicographically Sortable Identifier) format:

```regex
^[0-9A-HJKMNP-TV-Z]{26}$
```

Explanation:
- `^` asserts the start of the string.
- `[0-9A-HJKMNP-TV-Z]` matches any character in the range 0-9, A-H, J-K, M-N, P-T, or V-Z.
- `{26}` specifies that the preceding character class should occur exactly 26 times (the length of a ULID).
- `$` asserts the end of the string.

Note that ULIDs are case-sensitive and use a modified base32 encoding, excluding the characters I, L, O, and Q to avoid confusion with numerals.

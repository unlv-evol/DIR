Yes, you can create a spinner or loading indicator in a React application to show loading state on every page. One common approach is to use a global state management solution, such as React Context or Redux, to manage the loading state across the entire application. Here's a basic example using React Context:

1. **Create a context for managing the loading state:**

```jsx
// LoadingContext.js
import React, { createContext, useState, useContext } from 'react';

const LoadingContext = createContext();

export const LoadingProvider = ({ children }) => {
  const [isLoading, setLoading] = useState(false);

  const startLoading = () => {
    setLoading(true);
  };

  const stopLoading = () => {
    setLoading(false);
  };

  return (
    <LoadingContext.Provider value={{ isLoading, startLoading, stopLoading }}>
      {children}
    </LoadingContext.Provider>
  );
};

export const useLoading = () => {
  return useContext(LoadingContext);
};
```

2. **Wrap your entire application with the `LoadingProvider`:**

```jsx
// App.js
import React from 'react';
import { LoadingProvider } from './LoadingContext';
import Routes from './Routes';

const App = () => {
  return (
    <LoadingProvider>
      <Routes />
    </LoadingProvider>
  );
};

export default App;
```

3. **Use the loading context in your components:**

```jsx
// YourComponent.js
import React, { useEffect } from 'react';
import { useLoading } from './LoadingContext';

const YourComponent = () => {
  const { startLoading, stopLoading } = useLoading();

  useEffect(() => {
    // Simulate an asynchronous operation (e.g., API call)
    startLoading();
    setTimeout(() => {
      // Your actual logic here
      stopLoading();
    }, 2000);
  }, [startLoading, stopLoading]);

  return (
    <div>
      {/* Your component content */}
    </div>
  );
};

export default YourComponent;
```

4. **Create a Spinner component:**

You can create a reusable Spinner component that you can use in different parts of your application. You can find many pre-built spinner components or create a simple one using CSS.

```jsx
// Spinner.js
import React from 'react';

const Spinner = () => {
  return (
    <div className="spinner">
      {/* Your spinner content (e.g., loading animation) */}
      Loading...
    </div>
  );
};

export default Spinner;
```

Now, whenever you want to indicate a loading state in your components, you can use the `useLoading` hook to access the loading context and show the spinner accordingly.

Sure, deprecating a method in TypeScript involves marking it as deprecated using a JSDoc comment with `@deprecated` tag. Here's an example:

```typescript
class MyClass {
    /**
     * @deprecated This method is deprecated. Use myNewMethod instead.
     */
    oldMethod() {
        // Deprecated method implementation
    }

    myNewMethod() {
        // New method implementation
    }
}

const obj = new MyClass();

// Using the deprecated method
obj.oldMethod(); // This will generate a warning in most IDEs and linting tools
```

In this example, the `oldMethod()` is marked as deprecated using the `@deprecated` JSDoc comment. When developers use this method, they will receive a warning indicating that it's deprecated and should be replaced with `myNewMethod()`.

Yes, you can replicate the functionality of formatting a date using the "Do (ddd) MMMM YYYY" format with DayJS. DayJS is a lightweight JavaScript library for parsing, manipulating, and formatting dates.

To achieve the same result as the moment.js code you provided, you can use DayJS's `format()` function. Here's an example:

```javascript
const dayjs = require('dayjs');
require('dayjs/locale/en'); // Import the locale you want to use (e.g., 'en' for English)

const formattedDate = dayjs(event.date).format("Do (ddd) MMMM YYYY");
console.log(formattedDate);
```

Make sure you have DayJS installed in your project by running `npm install dayjs`. Also, don't forget to import the locale you want to use if you need to localize the output.

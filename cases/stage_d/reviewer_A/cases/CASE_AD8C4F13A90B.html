To get the width of the scrollbar with JavaScript, even when the scrollbar is not displayed in the browser, you can follow these steps:

1. Create a hidden element that has an overflow property set to `scroll`. This will force the scrollbar to appear, even if the content doesn't overflow.

2. Measure the width of the scrollbar by calculating the difference in width between the container's client width and its scroll width.

3. Remove the hidden element from the DOM if you no longer need it.

Here's an example of how you can do this:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Get Scrollbar Width</title>
    <style>
        /* Hide the scrollbar in normal elements */
        .hidden-scrollbar {
            overflow: hidden;
        }
        
        /* Force the scrollbar to appear in this element */
        .scrollbar-measure {
            width: 100px;
            height: 100px;
            overflow: scroll;
            visibility: hidden;
            position: absolute;
        }
    </style>
</head>
<body>
    <div class="hidden-scrollbar">
        Content here
    </div>

    <div class="scrollbar-measure" id="scrollbar-measure"></div>

    <script>
        // Function to get the scrollbar width
        function getScrollbarWidth() {
            const scrollbarMeasure = document.getElementById('scrollbar-measure');
            return scrollbarMeasure.offsetWidth - scrollbarMeasure.clientWidth;
        }

        // Call the function to get the scrollbar width
        const scrollbarWidth = getScrollbarWidth();
        console.log(`Scrollbar Width: ${scrollbarWidth}px`);

        // Remove the scrollbar-measure element from the DOM
        scrollbarMeasure.remove();
    </script>
</body>
</html>
```

In this example, we create a hidden `div` with the class `scrollbar-measure` and set its `overflow` property to `scroll`. We then calculate the scrollbar width by subtracting the client width from the offset width of this element. Finally, we remove the `scrollbar-measure` element from the DOM.

This approach should give you the scrollbar width even when the scrollbar is not displayed in the browser.

To disable a submit button in HTML using JavaScript after the form has been submitted, you can follow these steps:

1. **HTML Setup**: First, ensure your submit button has an identifiable attribute, like an `id` or a `class`. For example:

    ```html
    <form id="myForm">
        <!-- Your form inputs here -->
        <button type="submit" id="submitButton">Submit</button>
    </form>
    ```

2. **JavaScript Logic**: You need to add an event listener to your form that triggers when the form is submitted. Inside this event, you can disable the submit button.

    Here's an example using plain JavaScript:

    ```javascript
    document.getElementById('myForm').addEventListener('submit', function(event) {
        // Disable the submit button
        document.getElementById('submitButton').disabled = true;

        // Optional: Prevent form from submitting if you need to do something else
        // event.preventDefault();
    });
    ```

    This script listens for the `submit` event on the form and, when triggered, disables the submit button.

3. **Placement of JavaScript**: Make sure your JavaScript is placed after the HTML form in your document, or run it after the document has loaded. This is important to ensure that the elements exist in the DOM when your script tries to access them.

By following these steps, the submit button will be disabled immediately when the form is submitted, preventing multiple submissions and indicating to the user that their submission is being processed.
